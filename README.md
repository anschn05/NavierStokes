# Simulation-der-Navier-Stokes-Gleichungen-mit-Hilfe-von-k-nstlicher-Intelligenz

Die Seminararbeit 'Simulation der Navier-Stokes-Gleichungen mit Hilfe von künstlicher Intelligenz' von Anna Sonnleitner, Emanuel Steininger und Martin Strobl für den Bachelor-Studiengang 'Technische Mathematik' an der TU Wien

## Zugang zu den drei Projekten
Dieser Repository hat 3 zusätzliche Branches, wobei jeder einzelne ein fertiges Projekt beinhaltet, in den README-Dateien der jeweiligen Branches befinden sich kurze Anleitungen, wie die entsprechenden Codes compiliert bzw. ausgeführt werden können.

Hier im 'main'-Branch befindet sich die schriftliche Seminararbeit in Form eines PDF-Files.
